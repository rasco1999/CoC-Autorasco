# CoC-Autorasco

Independent Clash of Clans attack-planning assistant for Town Hall 15–18.

## MVP scope
- Import an enemy village screenshot.
- Guided visual analysis of visible structures, walls, compartments, and likely entry points.
- Recommend candidate attack approaches and explain trade-offs.
- Present a manual visual plan: deployment direction, troop sequencing, hero timing, spell timing, and risk notes.
- Mark uncertain detections and hidden-trap assumptions clearly.

## Boundaries
- No gameplay automation, simulated taps, game-client control, or connection to Supercell game servers.
- No guarantee of a three-star result.
- Hidden traps and unseen information are estimates, never confirmed detections.

## Supported Town Hall levels
TH15, TH16, TH17, TH18.

## UX
Arabic-first, right-to-left interface. Manual visual explanation and ordered steps; no automated execution.
